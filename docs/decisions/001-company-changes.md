# 001 - Company profile changes

1. Product changed to a prepaid payroll card for gig workers. Reason: payroll cards hold wages, so exposure of customer funds and identity data has a clear, serious impact.
2. 2. Cloud changed to Azure. Reason: Azure is common in Irish enterprise environments and uses different identity and logging services from AWS.
3. MFA not enforced for the support team. Reason: support staff can see KYC documents, so a missing control on a high-access group makes a realistic, testable risk.
